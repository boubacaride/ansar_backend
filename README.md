# Ask Ansar — Backend

Node/Express API for Ask Ansar. MVC layout: `routes/` → `controller/` → `services/` →
`model/` (+ `schema/` validation, `middlewares/` auth, `config/` env wiring).

Run: `npm install && node index.js` (env vars per `config/`).

Related: the Ask Ansar apps and docs live in sibling repos/folders
(`ansar-verification`, `ansar-docs`, Google sign-in branding runbook in the ops vault).
